# 피클 사운드 (Galaxy Watch / Wear OS)

피클볼 칠 때 공이 패들에 맞는 순간 워치에서 효과음(+진동)이 나는 앱.

## 설치 방법
1. PC에 Android Studio 설치 → 이 폴더(PickleSound)를 "Open"으로 열기 (Gradle 동기화는 자동)
2. 워치: 설정 → 워치 정보 → 소프트웨어 정보 → "소프트웨어 버전" 7번 탭 → 개발자 옵션 켜기
3. 개발자 옵션 → "ADB 디버깅", "무선 디버깅" 켜기 (PC와 같은 Wi-Fi)
4. 무선 디버깅 화면의 "새 기기 페어링"에 나오는 IP:포트, 코드로 PC 터미널에서:
   adb pair IP:페어링포트   (코드 입력)
   adb connect IP:연결포트
5. Android Studio 상단 기기 목록에서 워치 선택 → ▶ Run

## 사용법
- 패들 드는 손 손목에 차고 [시작] → 타구 시 소리
- 화면의 "충격 N / 기준 M": 공을 칠 때 충격값이 기준보다 크고, 그냥 휘두를 때는 작게 나오도록 감도 조절
  - 헛스윙에도 울리면 감도 ↓, 쳤는데 안 울리면 감도 ↑
- 효과음 3종(팡/딱/뿅), 진동 켜기/끄기, 설정은 자동 저장
- 감지 중엔 화면이 켜진 채 유지됨 (앱을 나가면 자동 정지)
- 소리가 작으면 워치의 미디어 볼륨을 올리세요. 블루투스 이어폰이 연결돼 있으면 그쪽으로 소리가 납니다.
